# Flux — yt-dlp Web UI

واجهة ويب عربية/إنجليزية مبنية بـ HTML/CSS/JavaScript، وخلفية Python تستخدم yt-dlp لاستخراج معلومات الوسائط وتنزيلها فعليًا.

## الملفات

- `index.html` — الواجهة.
- `style.css` — التصميم المتجاوب والوضع الفاتح/الداكن.
- `script.js` — التفاعل مع API وعرض البيانات الحقيقية.
- `app.py` — API: تحليل الرابط، إدارة مهام التنزيل، الحالة، وإرسال الملف.
- `requirements.txt` — مكتبات Python.
- `Procfile` و`render.yaml` — إعداد تشغيل خدمة Python على Render.
- `vercel.json` — إعداد واجهة ثابتة على Vercel (الواجهة وحدها لا تشغّل محرك التنزيل).

## تنبيه استضافة مهم

`yt-dlp` ليس محرك JavaScript داخل المتصفح؛ يحتاج Python وبيئة خادم. Vercel مناسب لاستضافة الواجهة الثابتة، لكنه ليس المكان المناسب لتمرير ملفات فيديو كبيرة عبر دوال serverless. ملف `app.py` مصمم ليعمل كخدمة Python طويلة التشغيل. لتجربة مجانية بأقل تعقيد، انشر المستودع كخدمة Web Service على Render باستخدام `render.yaml`؛ لا حاجة إلى Railway. الخطة المجانية قد تنام عند عدم الاستخدام، والموارد والمهلة والمساحة المؤقتة محدودة، لذلك لا يمكن ضمان تنزيل كل ملف أو كل موقع مجانًا. تنزيلات طويلة أو كبيرة قد تفشل على أي استضافة مجانية محدودة.

## النشر المجاني الأبسط (خدمة واحدة)

1. فك ضغط الأرشيف وارفع **محتويات** المجلد إلى مستودع GitHub جديد، بحيث تكون `app.py` و`index.html` و`requirements.txt` في جذر المستودع.
2. أنشئ حسابًا مجانيًا على Render، ثم اختر **New + → Blueprint** واربط مستودع GitHub.
3. وافق على إعداد الخدمة من `render.yaml`. تأكد أن الخطة `free`.
4. انتظر اكتمال البناء، ثم افتح رابط Render الناتج. يتضمن أمر البناء محاولة تثبيت FFmpeg؛ راجع `/api/health` وتأكد أن `ffmpeg: true` قبل تجربة دمج الفيديو والصوت أو تحويل الصيغ.
5. اختبر `/api/health`؛ المفروض يرجع JSON فيه `ok: true` ونسخة yt-dlp وحالة FFmpeg.
6. جرّب رابطًا عامًا لمحتوى مسموح لك بتنزيله.

> Render خدمة خارجية مجانية ضمن حدودها وقد تتغير شروطها. هذا المشروع لا يستخدم Railway.

## استخدام Vercel

`vercel.json` مخصص لنشر الواجهة الثابتة فقط. عند نشرها على Vercel، يلزم ضبط `API_BASE_URL` في `script.js` على عنوان خدمة Python العامة، وتعديل طلبات `/api/...` لتستخدم ذلك العنوان؛ المتصفح يحتاج كذلك أن تسمح خدمة Python بطلبات CORS من نطاق Vercel. لتقليل التعقيد، استخدم خدمة Render الواحدة أولًا؛ فهي تخدم الواجهة وAPI من نفس الأصل دون إعداد CORS.

## حدود حالية معلنة

- حجم الملف الناتج محدود افتراضيًا بـ 450 MB (`FLUX_MAX_OUTPUT_MB`) لتناسب موارد الاستضافة المجانية؛ يمكن تعديل الحد لكنه لا يخلق مساحة أو ذاكرة إضافية.
- الحد الافتراضي لمهمة تنزيل نشطة واحدة على Render المجاني (`FLUX_MAX_JOBS=1`).
- الأحجام التي يعرضها yt-dlp قد تكون تقريبية أو غير متاحة، والدمج/التحويل قد يغير الحجم النهائي.
- المعاينة المباشرة غير مضمونة لكل موقع؛ الواجهة تعرض الصورة المصغرة وبيانات الفيديو، ولا تدّعي تشغيل مصادر لا يمكن للمتصفح تشغيلها.
- دعم المواقع يتغير مع تحديثات المواقع وyt-dlp.
- لا يوجد تجاوز DRM أو حماية أو تسجيل دخول للمحتوى الخاص.
- لا توجد بيانات اعتماد مطلوبة افتراضيًا. لا تضع أسرارًا في ملفات الواجهة العامة.

## تشغيل محلي (اختياري)

يتطلب Python 3.10+ وFFmpeg موصى به:

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

افتح `http://localhost:8000`.
